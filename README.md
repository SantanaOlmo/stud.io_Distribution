# estud.io (distribución)

PWA pública de **estud.io**. Este repositorio contiene **solo** los archivos compilados servidos por GitHub Pages.

- App: https://santanaolmo.github.io/stud.io_Distribution/
- El código fuente es privado y no se publica aquí.
- Tus datos (carpetas, tarjetas, historial) viven solo en tu dispositivo (IndexedDB); no se suben a GitHub.

Instalación: abre la URL en Chrome (Android) → Instalar aplicación. Las actualizaciones aparecen como «Nueva versión disponible» sin borrar tus datos.
